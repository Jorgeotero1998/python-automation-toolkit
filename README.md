# Python Automation Toolkit 🚀

Framework profesional para automatización web indetectable y escalable.

## 🛠️ Características
- **Stealth Mode**: Comportamientos humanos para evadir detecciones.
- **Robust Logging**: Capturas de pantalla y logs ante errores.
- **Session Management**: Persistencia de cookies y estados.

## 📁 Estructura
- /core: Motores del navegador.
- /utils: Helpers de comportamiento y logger.
